# XSD схемы для валидации XML

В этой директории размещаются XSD схемы для валидации XML файлов.

## Использование

1. Поместите XSD-схему в эту директорию (расширение `.xsd`)
2. На странице «Валидация XML» выберите схему из списка
3. Система проверит загруженный XML на соответствие схеме

## Рабочая схема

- `journal3.xsd` — схема journal (elibrary) для производственных XML выпуска
