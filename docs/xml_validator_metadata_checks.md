# Валидатор XML — смысловые проверки метаданных

Документ описывает **содержательные** проверки сервиса «Валидатор XML»
(`check_metadata` / `analyze_journal_xml`), а не проверку по XSD-схеме.

Код: `ipsas/modules/journal_xml/validators.py` (`collect_article_issues`),
парсинг источников — `parser.py`.

---

## Что это не делает

- Не заменяет и не дублирует **XSD / синтаксис XML** (это отдельный шаг `check_schema`).
- Не проверяет длину аннотации в словах (число слов только **показывается** в отчёте).
- Не требует зеркального числа источников RUS = ENG = UNK (в таблице «Источники по статьям» расхождение лишь **подсвечивается**, в список ошибок не попадает).
- Для материалов типа «только название» не требует авторов, аннотации, ключ. слов и источников.

---

## Профиль статьи

Перед проверками статья классифицируется:

| Профиль | Когда | Что обязательно |
|---------|--------|-----------------|
| **scientific** | `artType` из научного набора (RAR, REV, SCO, CLA, …) **или** неизвестный/пустой тип | названия + аннотация + ключ. слова + авторы + источники |
| **title_only** | `artType` BRV/PER/MEM/… **или** в названии признаки юбилея/некролога/рецензии на книгу | только названия RUS и ENG |

Правило зеркала: **на ENG требуется то, что уже есть на RUS** (если на RUS есть аннотация / ключ. слова — на ENG они тоже должны быть).

---

## Критичные ошибки (`critical`)

Статья в отчёте помечается как «Ошибки», если есть хотя бы одна.

### Названия (любой профиль)

- нет названия (RUS)
- нет названия (ENG)

### Аннотация

- **scientific:** нет аннотации RUS
- есть RUS, нет ENG → нет аннотации ENG

### Ключевые слова

- **scientific:** нет ключевых слов вообще / нет RUS
- есть RUS, нет ENG → нет ключевых слов (ENG)  
  (для `title_only` отсутствие ENG при наличии RUS — только предупреждение)

### Источники

- **scientific:** нет ни одного источника (RUS + ENG + UNK + ANY = 0)

### Авторы (**только scientific**)

- нет авторов
- у автора нет ФИО (RUS)
- есть RUS, нет ENG

---

## Предупреждения (`secondary`)

Статья без critical, но с secondary → «Замечания».

### Аннотация / ключ. слова / авторы

- есть ENG, нет RUS (аннотация / ключ. слова / данные автора)
- нет аффилиации (RUS) или (ENG), если соответствующее ФИО есть
- разное **количество** ключевых слов RUS ≠ ENG  
  (текст: «Ключевые слова — разное количество: RUS=…, ENG=…»)
- для `title_only`: есть RUS-ключ. слова, нет ENG

### Оформление списка литературы

- источники начинаются с явной нумерации (`1. …` / `12) …`) —  
  «список литературы содержит нумерацию (N из M)»
- один и тот же текст продублирован и в `<reference>`, и в `<refInfo>/<text>` —  
  «дублирование текста источников (…)»

---

## Статусы в карточке статьи (инфо, не всегда в issues)

Показываются в деталях отчёта:

| Блок | Смысл |
|------|--------|
| Ключевые слова | ✅/❌ по языкам; сравнение числа RUS/ENG |
| Источники | «✅ Источники есть (RUS=…, ENG=…, UNK=…)» или «❌ Источники отсутствуют»; превью первого/последнего по языку |
| Таблица «Источники по статьям» | сводка по выпуску; **жёлтым** — статьи, где ненулевые языки расходятся по числу |

---

## Сводка выпуска

В шапке отчёта дополнительно считаются:

- статей всего / без замечаний / с ошибками / с предупреждениями
- сколько статей без названия ENG, без аннотации ENG, без keywords ENG

---

## Краткая шпаргалка

```
Любая статья:     title RUS + title ENG
Научная:          + abstract RUS (+ ENG если есть RUS)
                  + keywords (+ ENG если есть RUS)
                  + авторы с RUS/ENG ФИО
                  + хотя бы 1 источник
                  аффилиации — желательны (warning)
Поздравления/BRV: достаточно title RUS+ENG
Литература:       без «1.» в тексте; без дубля reference/refInfo
```
