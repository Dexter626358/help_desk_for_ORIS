Анализ XML журнала

Описание сервиса

Сервис принимает XML по схеме journal (elibrary / journals) и проверяет заполненность полей выпуска и статей, а также наличие англоязычных метаданных.

  • названия, аннотации и ключевые слова (RUS / ENG);
  • ФИО авторов и аффилиации на русском и английском;
  • количество источников с тегами RUS, ENG, UNK (и ANY); ошибка — только если источников нет совсем;
  • сводка проблем по выпуску и детальный отчёт по каждой статье.
Результат показывается на экране; дополнительно можно скачать полный HTML‑отчёт.
Поддерживаются только файлы с расширением .xml (корневой элемент journal).
