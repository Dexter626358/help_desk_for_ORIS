# Быстрый старт IPSAS

## Установка и запуск

### 1. Активация виртуального окружения

```bash
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# Windows Command Prompt
venv\Scripts\activate.bat
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка пакета в режиме разработки (опционально)

```bash
pip install -e .
```

### 4. Запуск сервера

```bash
python run.py
```

### 5. Открыть в браузере

Перейдите по адресу: **http://localhost:5000**

Авторизация не требуется — сервисы открываются сразу с дашборда.

## Основные сервисы

- Валидация XML (XSD)
- Анализ XML журнала
- Обработка списков литературы
- Парсер выпуска по URL
- CSV PDF выпуска

## Остановка сервера

Нажмите `Ctrl+C` в терминале.
