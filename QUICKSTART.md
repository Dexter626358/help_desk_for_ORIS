# Быстрый старт IPSAS

## Установка и запуск

### 1. Активация виртуального окружения

```bash
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# Windows Command Prompt
venv\Scripts\activate.bat
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка пакета в режиме разработки (опционально)

```bash
pip install -e .
```

### 4. Запуск сервера

```bash
python run.py
```

### 5. Открыть в браузере

Перейдите по адресу: **http://localhost:5000**

Авторизация не требуется — сервисы открываются сразу с дашборда.

## Основные сервисы

- Валидатор XML (XSD и метаданные)
- Исправить типовые ошибки XML
- Исправить список литературы
- Добавить PDF в XML
- Проверить опубликованный выпуск
- Сформировать CSV для загрузки PDF
- Проверить сайт журнала
- Обработать редакционную коллегию

## Остановка сервера

Нажмите `Ctrl+C` в терминале.
