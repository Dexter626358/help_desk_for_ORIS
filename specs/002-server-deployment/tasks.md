# Tasks: Развёртывание IPSAS на внутреннем сервере

**Input**: Design documents from `/specs/002-server-deployment/`

**Prerequisites**: spec.md, plan.md (готовы). `research.md`, `data-model.md`, `contracts/`
не создаются — фича не вводит новых сущностей предметной области и API-контрактов.

**Tests**: smoke-тест живого экземпляра (`deploy/smoke-test.sh`, `deploy/smoke-test.ps1`)
покрывает User Stories 1, 3 и 4. Автотесты приложения не добавляются: код `ipsas/` не
меняется, но существующие 263 теста MUST остаться зелёными.

> **Происхождение документа.** Список составлен задним числом, по фактически выполненной
> работе. Отметки `[x]` означают, что работа выполнена и проверена на сервере.

**Organization**: Задачи сгруппированы по user stories. Легенда: `[x]` — выполнено и
проверено, `[ ]` — осталось.

## Format: `[ID] [P?] [Story] Description`

- **[Story]**: user story, к которому относится задача (US1 … US6)
